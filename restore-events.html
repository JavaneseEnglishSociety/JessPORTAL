Restore JESS events

This tool writes back only the events field of your site. Every other field — team, gallery, partners, news, programs, contact details, theme — is read and written back exactly as it already is, untouched.

Read this first.
  • Click Load current site first. It shows you what events are in Firestore right now, before changing anything.
  • If your real events are already there, close this page. Nothing needs restoring.
  • Only click Restore if the events shown are wrong or missing.
  • A backup of the current state is downloaded automatically before any write.
